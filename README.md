WinDivert может вызвать ответ антивируса.
WinDivert - это инструмент для перехвата и фильтрации трафика, выбранный для блокировки работы. Он может использоваться как хорошими, так и плохими программами, но сам по себе не является вирусом.

* Выдержка из readme.mdрепозитория bol-van/zapret-win-bundle

Некоторые антивирусы склонны относить файлы WinDivert к классам повышенного риска или хакерским инструментам. Происходит удаление файла и помещение его в карантин. При этом детект обязательно имеет название WinDivertилиNot-a-virus:RiskTool.Multi.WinDivert

Добавьте указание с запретом в выключении антивируса, либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в касперском есть галочка «Обнаруживать легальные приложения, которые злоумышленники часто используют для распространения вреда». Аккуратно и с помощью логика настройки исключений рекомендуется настроить настройки, но если вы не до конца поняли, что делаете, рекомендуется включить обнаружение PUA.

⚙️Использование
Включите Безопасный DNS (Secure DNS)

В Chrome — «Использовать безопасный DNS» и выбрать поставщика услуг DNS (выбрать вариант, отличный от оператора «Поставщик по умолчанию»)
В Firefox - «DNS через HTTPS», выберите режим «Персональный», затем «Выбрать провайдера/поставщика» и впишите URL поставщика вручную. Например, можно использовать https://dns.google/dns-query(т.к. поставщик Cloudflare может быть заблокирован)
В Windows 11 инструкции включают Secure DNS непосредственно в операционной системе — инструкция здесь . Обратите внимание, если вы пользуетесь Windows 11
Если у вас роутер Keenetic, в подключении роутера есть опция «Транзит запрос». Отключение этой опции может привести к проблемам при настройке и использовании Secure DNS на компьютере.

ℹ️Краткие описания файлов
general.bat ...- запуск стратегии вручную

Запуск вручную можно использовать для проверки работоспособности стратегии. Работоспособность той или иной стратегии зависит от многих факторов. Попробуйте разные стратегии (ALT, FAKE и другие), пока не найдете игровое для вас решение.

service.bat- установка в автозапуск и другие функции:

Install Service- установка любой стратегии в автозапуск (services.msc)
Remove Services- удаление стратегий и WinDivert из сервисов
Check Status- проверка условий обхода и обслуживания (стратегии на автозапуске и WinDivert)
Game Filter- переключение режима обхода для игр (и других сервисов, использующих UDP и TCP на портах выше 1023).
После переключения требуется перезапуск стратегии.
В скобках указан текущий статус (включено/выключено).
IPSet Filter- переключение режима обхода сервисов из ipset-all.txt.
Полезно при тестировании, если не работает ресурс, который без запрета работает.
В скобках указан следующий статус:
none- никакие айпи не оставлены при проверке
loaded- айпи недавно перешёл в список
any- Любой айпи открывается под фильтр
Auto-Update Check- Вкл/Выкл автоматическая проверка на обновления
Replace active fakes- Заменить указанный фейк прогноза на другом из папок.bin
Update IPSet List- обновление ipset-all.txtактуального списка из репозитория
Update Hosts File- обновление файла hostsдля починки веб-версии телеграма и подключения к голосовому чату Discord
Check for Updates-проверка на обновление
Run Diagnostics- диагностика на распространённые причины, по которым запрет может не работать.
В конце концов можно использовать кэш , что может помочь, если он неожиданно прервал работу. Discord
Run Tests- запускаем утилиты для проверки стратегий работоспособности:
Standard tests-проверка сайтовutils/targets.txt
DPI checkers-проверка DPI на различных провайдерах (Cloudflare, Amazon и др.)
☑️Распространенные вопросы и проблемы.
После запуска скрипта general*ничего не происходит
После запуска стратегии (отдельным bat-файлом, не через сервис) должен открыться winws.exe (обход), который можно увидеть в панели задач.
Если этого не произошло, то см. #522
Ни одна стратегия не подходит
Запустите командную строку от имени администратора

Последовательно введите команду в консоль:

netsh winsock reset

netsh int ip reset all

netsh winhttp reset proxy

ipconfig /flushdns

Перезагрузите компьютер

Не работает телеграм (веб-версия)
Запустите service.bat, выберите пункт Update hosts file. После этого, если ваш хост окажется неактуальным, то Вам будет предложено обновить его самостоятельно:

Скопируйте весь текст открывшегося блокнота
Откройте файл hostsв появившемся файле с помощью текстового редактора, открытого от имени администратора.
добавить в конец файла hostsто, что скопировали (или заменить, если до этого Вы уже добавляли подобное)
Сохраните и перепроверьте подключение. Если не работает - убедитесь, что файл hostsдействительно сохраняется.
Работа не гарантирована. Если не помогло - используйте версию для ПК с локальным прокси или любыми публичными.

Важный

Стратегии со временем могут переставить работу. Определенная стратегия может сработать какое-то время, но со временем она может переставить работу из-за обнаружения. В репозитории представлено множество различных приемов обхода. Если ни одна из них вам не поможет, то вам необходимо создать новую, взяв за основу вещь из представленных здесь и изменив ее параметры. Проверьте, что в service.bat Game Filter disabled, а IPSet Filter none. В противном случае это может повлиять на доступность ресурсов, которых вы не ожидали.

🗒️Добавление адресов внешних ресурсов
Список адресов для обхода можно увеличивать, добавляя их в:

list-general-user.txtдля доменов (поддомены автоматически наблюдаются)
list-exclude-user.txtдля исключения доменов (например, если айпи указал сеть в ipset-all.txt, но конкретный домен из этой сети не надо фильтровать)
ipset-all.txtдля IP и подсетей
ipset-exclude-user.txtдля исключения IP и подсетей
Файлы *-user.txtавтоматически создаются при первом запуске zapretилиservice.bat
